## 先搞清楚：住宅 IP、双 ISP、原生 IP 到底差在哪

很多人把这三个词混着用，但丽萨主机官网上它们是分开标的产品线，价格也差不少。

**机房原生 IP**：IP 归属地在当地，但归属者是数据中心 ASN（比如 AS9929、CN2 GIA 这种线路背后的运营商）。优点是线路优化好、回程快；缺点是 IP 属性是"机房"，对 TikTok、Netflix 这类查 IP 类型的平台来说，识别度较高，解锁能力看运气。

**住宅 IP（家宽 IP）**：IP 来自真实家庭宽带出口，归属者是住宅 ISP，在 IP 库里被标记为 residential。TikTok、Instagram、亚马逊这类对 IP 类型敏感的平台，住宅 IP 通过率明显高于机房 IP。

**双 ISP 住宅 IP**：同一个 IP 同时登记在两家运营商名下，IP 信誉评分（Scamalytics 这类）通常更低，被风控系统判为"可疑"的概率更小。丽萨主机主推的就是这个属性，也是它和普通住宅 IP VPS 拉开价差的关键点。

简单说：如果你只是要个能解锁 Netflix 的 VPS，机房原生 IP 可能就够；如果你要跑 TikTok 美区号、做 FB/WhatsApp 营销、养亚马逊/Shopee 店铺，双 ISP 住宅 IP 才是真正对口的方案。

**非大陆优化线路的节点（新加坡、台湾、英国、德国、日本 IIJ）官方都建议中转**。如果你没有香港或日本的中转节点，直连速度可能不理想，下单前先确认你有中转条件，或者把中转成本算进总预算。

**特价年付版配置都很低**（1核1G/10G），适合长期挂着的轻量业务。如果你的业务会吃 CPU 或内存，年付版可能不够，老老实实选月付的进阶版或豪华版。

**"不限流量"套餐带宽被压得很低**。9929 不限流量 Lite 只有 20Mbps，4837 不限流量 Lite 200Mbps、Pro 500Mbps。不限流量不等于不限带宽，视频业务要看带宽够不够。

**IP 段会更新**。丽萨主机 periodically 上新 IP 段（比如之前推过的 192 号段、206 段），老 IP 段可能因为使用量大而纯净度下降。如果你对 IP 纯净度敏感，下单后可以工单问一下当前可分配的 IP 段，或者要求分配新段。

**住宅 IP 不等于绝对安全**。双 ISP 住宅 IP 能显著降低风控触发率，但平台风控还看行为模式、设备指纹、账号注册信息等。IP 是必要条件不是充分条件，业务该做的合规和防关联还是要做。
